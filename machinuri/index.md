# まちぬり

行った市区町村を塗って、日本地図を塗りつぶそう。旅の記録アプリです。

全国 1,741 の市区町村のうち、訪れた場所を地図に塗って「踏破率」を育てていきます。カメラロールの撮影場所からまとめて塗ったり、塗った地図をシェアカードにして SNS に投稿したりできます。

## よくある質問

### 写真や位置情報はどこかに送られますか？
送られません。撮影場所や現在地からの市区町村の判定は、すべて端末の中で行います。アプリに保存されるのは「どの市区町村を・どの段階で・いつ塗ったか」だけです。詳しくは[プライバシーポリシー](privacy/)をご覧ください。

### 機種変更したら記録はどうなりますか？
記録は端末の中にだけ保存されています。機種変更の前に、アプリの「設定 → バックアップを書き出す」でファイルを保存してください。新しい端末では「設定 → バックアップから復元」に、ファイルの中身を貼り付けて読み込みます。

### 写真から取り込んでも一部しか見つかりません
写真へのアクセスを「選択した写真のみ」にしている場合は、選んだ写真だけが対象になります。「設定」アプリ → まちぬり → 写真 で「フルアクセス」を選んでください。また、撮影場所が記録されていない写真 (位置情報をオフにして撮った写真やスクリーンショットなど) は判定できません。

### 政令指定都市の数え方を変えたい
「設定 → 政令市は市単位で数える」をオフにすると、横浜市の 18 区などをそれぞれ 1 つとして数えます (全国 1,741 → 1,892)。記録は区ごとに持っているので、いつでも切り替えられます。

### 市区町村の境界がずれている気がします
地図は国土交通省の行政区域データを、アプリで扱いやすいように簡略化して使っています。海岸線や境界付近では、数百 m 程度ずれることがあります。

### 「まちぬり Pro」を別の端末でも使いたい
同じ Apple ID でサインインした端末で、「設定 → まちぬり Pro」から購入を復元してください。月額プランの解約は、「設定」アプリ → 自分の名前 → サブスクリプション から行えます。
