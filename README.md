# tsutsumi03.github.io

アプリの公開ページ (紹介・プライバシーポリシー・サポート窓口) を 1 か所にまとめたリポジトリです。
Public pages for my apps, in one place.

## 構成

```
index.md                アプリ一覧
<アプリ名>/index.md     紹介・サポート
<アプリ名>/privacy.md   プライバシーポリシー (日英)
```

新しいアプリは、フォルダを 1 つ足して、`index.md` と `privacy.md` を置く。URL は `https://tsutsumi03.github.io/<アプリ名>/privacy`。
